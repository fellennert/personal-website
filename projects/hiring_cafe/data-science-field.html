Relationship Between Salary and Applicant Count

I extracted applicant counts by parsing the appliedFromUsers field, which contains list data. A Poisson regression model was fitted to examine the relationship between minimum salary and number of applicants, as Poisson regression is appropriate for count data.

The model coefficients were exponentiated to obtain incidence rate ratios (IRRs). The analysis calculates both the percentage change in expected applicants per dollar increase in salary and per $10,000 increase. This provides insight into how compensation levels affect job competitiveness.

Skill Standardization

Technical skills are often listed with variations in naming (e.g., “python 3”, “py”, “Python”). To address this, I used an LLM (Qwen 2.5 7B via Langchain and Ollama) to standardize skill names. The prompt instructed the model to generalize skill names while retaining specific tool names (like “tensorflow” or “transformers”).

Processing occurred in batches of 50 skills. For each batch, the LLM returned a dictionary mapping original skill names to standardized versions. The output was extracted using regex to find Python dictionary syntax within markdown code blocks, then parsed with ast.literal_eval().

Show code 
from langchain_core.prompts import ChatPromptTemplate
from langchain_ollama import OllamaLLM
from langchain_core.output_parsers import StrOutputParser
import json
import re

unique_skills = technical_tools_count[technical_tools_count['count'] > 5].sort_values(['job_data.technical_tools']).reset_index()

llm = OllamaLLM(model="qwen2.5:7b", temperature=0)

prompt_template = ChatPromptTemplate.from_template(
    """Standardize these technical skills to common names. 
    For each skill, provide ONLY a more generalized skill. For specific applications or software packages (e.g., transformers, tensorflow, tableau), retain the original name.

    For instance: 'R programming' --> 'R', 'statistical modeling' --> 'statistics', 'statsmodels' --> 'statsmodels', 'unix' --> 'unix', 'tensorflow' --> 'tensorflow'
    
    Skills to standardize:
    {skills}
    
    Return as a Python dictionary mapping original -> standardized name. Example:
    {{'python 3': 'python', 'py': 'python'}}"""
)

chain = prompt_template | llm | StrOutputParser()

batch_size = 50
skills = unique_skills['job_data.technical_tools']
all_mappings = []

for i in range(0, len(skills), batch_size):
    batch = skills[i:i+batch_size]
    result = chain.invoke({"skills": str(batch)})
    match = re.search(r'```(?:python)?\s*(\{.*?\})\s*```', result, re.DOTALL)
    result_clean = match.group(1)
    try:
        batch_mapping = ast.literal_eval(result_clean)
        for original, standardized in batch_mapping.items():
            all_mappings.append({'original': original, 'standardized': standardized})
    except (ValueError, SyntaxError) as e:
        print(f"Skipped batch at index {i}: {e}")
        continue
    print(i)

skill_mappings_df = pd.DataFrame(all_mappings)

selected_df_unpacked = selected_df_unpacked.merge(
    skill_mappings_df,
    left_on='job_data.technical_tools',
    right_on='original',
    how='inner'
)

The standardized mappings were stored in a dataframe and merged with the unpacked job data, allowing for consistent skill counting across variant spellings.

Predictive Modeling

I constructed a linear regression model to predict log-transformed salary based on multiple features:

  • Workplace type (categorical)
  • Workplace state (categorical)
  • Seniority level (categorical)
  • Minimum years of experience (numeric)
  • Technical tools/skills (categorical)

The model preparation involved filtering to salaries between $10,000 and $500,000, removing rows with missing values, creating dummy variables for all categorical features using pd.get_dummies() with drop_first=True to avoid multicollinearity, log-transforming the dependent variable (salary), and fitting an OLS regression using statsmodels.

Technical Implementation

The analysis uses several Python libraries:

  • pandas for data manipulation
  • seaborn and matplotlib for visualization
  • statsmodels for regression modeling (both GLM for Poisson and OLS for linear regression)
  • sklearn for label encoding
  • ast for parsing string representations of lists
  • Langchain with Ollama for LLM-based skill standardization

All visualizations use consistent filtering (salaries between $10,000 and $500,000) to ensure comparability across plots. The categorical plots use custom ordering based on either natural progression (seniority levels, workplace types) or frequency (sectors, states) to enhance interpretability.
